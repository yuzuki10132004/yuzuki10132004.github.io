# AirPods コントロール

AirPods Pro 3 のノイズコントロールを1タップで切り替えるための、自分用のウェブアプリです。
GitHub Pages で配信し、iPhone の Safari から「ホーム画面に追加」して専用アプリとして使います。

ボタンは iPhone のショートカットを呼び出します。事前にショートカットアプリで、
アクション「ノイズコントロールモードを設定」を使って次の4つを作ってください
（AirPods を接続した状態で作ること）。

- `AirPods NC` … ノイズキャンセリング
- `AirPods 外部音` … 外部音取り込み
- `AirPods 適応型` … 適応型
- `AirPods オフ` … オフ

アイコン PNG は `*.png.b64` から GitHub Actions が生成してコミットします。
